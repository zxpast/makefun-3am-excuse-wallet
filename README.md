# The 3 AM Excuse

One line, in the voice of a hardware wallet that refuses to sign a transaction at 3 AM.

> It's 3 AM. My screen stays off: the last time I signed at this hour, you spent 2.4 ETH on a coin whose entire whitepaper was one eggplant emoji.

## The files

- `main.ts`: the entry, Node 22 and its standard library alone, run as `node main.ts`. It writes the single line (144 characters, under the 200-character gate) to `/output/entry.txt` and prints the same line to stdout. Deterministic: same bytes every run, no clock, no randomness, no network.
- `.makefun/owner.json`: the owner's wallet for the bounty.
